# 影子迁移运行手册

迁移 `000021` 继续以 PostgreSQL 作为记账权威。先运行离线 `migration-control`，它只执行 dry-run。导出有界且不含秘密的清单，由两个不同的授权 Ed25519 密钥对精确规范字节签名，再通过租户范围的管理 API 提交。

状态只能依次经过清单、验证、相互独立的请求/审批/执行、导入、影子和金丝雀。切换在独立认证的执行器确认精确动作版本和 fence 前保持待定。金丝雀中止与回滚保留观测、账本事实和事件归属围栏；导入的 watch-only 地址永不释放，也不得批量入账切换前的影子观测。

验证 Job 默认 `MIGRATION_EXECUTE=false`。写入还要求专用角色、lease/fence、双向 TLS 1.3、不同提供方主机及 quorum 签名事实。退役必须满足数据库计算的零积压，并具备不可变的归档、恢复测试和密钥撤销证据。

本地未运行真实源数据库、链、PostgreSQL 切换、执行器、Helm 集群或提供方 quorum；生产启用前须把这些证据写入发布清单。
