# 提供商运维

这是一个不暴露秘密的控制与健康平面。管理柜只显示稳定的提供商标识、操作、
策略/熔断版本、封闭状态类别、延迟、时间和审批人；不会显示 endpoint、凭据、
签名或托管材料、钱包地址及原始错误。

生产扫描器仅接纳启用且具有当前不可变 `rpc_provider` 审批证据、关闭熔断器和
来自独立故障域的新鲜 quorum 的链上提供商。paused、open、stale、divergent 均被
排除；低于 quorum 时扫描关闭。超时、重试、退避、限速、优先级和健康阈值都来自
已审批策略。

暂停与恢复是两个独立的四眼操作：请求人与近期 MFA 审批人必须不同，并绑定精确
版本、原因和 Idempotency-Key；状态、不可变审计和 outbox 在同一事务提交。私有
worker 监听 9100，使用 fenced lease 和按操作的只读 probe；readiness 要求非空成功
周期及可接纳的 peer 组。Hosted binding 初始为 paused：签名 callback 只作为
append-only 证据保存，不触发 ledger/settlement；在独立审批策略和成功 probe 之前，
所有出站调用保持关闭。

申请会把六项精确操作策略和一个有界、只写的初始状态引用绑定到不可变摘要中；
列表和审批响应绝不返回该引用。独立操作员完成近期 MFA 审批后，还必须从至少
两个独立故障域取得成功状态探测，并通过另一项四眼恢复审批，才会放行出站流量。
