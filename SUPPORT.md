# Support

ocrypt is pre-release open-source software. There is currently no production
support SLA, hosted service commitment, warranty, or authorization to process
real funds.

- Use a bug report for reproducible non-security defects involving synthetic
  data or systems you are authorized to test.
- Use a feature request for bounded product proposals.
- Use GitHub private vulnerability reporting for suspected security issues.
- Do not publish credentials, wallet material, personal data, or details of a
  live third-party system.

Questions about licenses and deployment responsibilities should begin with
[`docs/LEGAL.md`](docs/LEGAL.md), [`SECURITY.md`](SECURITY.md), and
[`docs/IMPLEMENTATION_STATUS.md`](docs/IMPLEMENTATION_STATUS.md). These files
are documentation, not legal, financial, security, or compliance advice.
